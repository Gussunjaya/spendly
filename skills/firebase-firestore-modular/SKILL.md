# Skill: Tailwind CSS v3 Utility Architecture

## Context

Rules for writing clean, responsive, and maintainable utility-first CSS layouts using Tailwind CSS v3.

## Rules for Code Generation:

1. **Responsive First:** Always design with a mobile-first approach using responsive modifiers (`sm:`, `md:`, `lg:`, `xl:`).
2. **Tabular Numerics:** For any financial metrics, balances, or currency displays, always apply the `font-mono` class to ensure clear tabular alignment.
3. **Component Spacing:** Maintain consistent layout padding and margins (`p-4`, `p-6`, `space-y-4`) to build spacious and high-fidelity interfaces.
4. **Theme Semantics:** Strictly use configured theme colors (such as slate neutrals, emerald for incomes, and rose for expenses) to ensure UI consistency.
